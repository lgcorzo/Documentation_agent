# UML 2.0 and OKF Documenter Skill

This skill enforces the use of Pyreverse for deterministic extraction of software architecture.
It converts the AST data into Mermaid.js UML 2.0 diagrams.
Output must follow the OpenWiki standards and use OKF v0.2 metadata.
